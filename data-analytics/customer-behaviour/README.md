# Customer Shopping Behaviour – Data Analytics Project

## 📌 Project Overview

This project performs exploratory data analysis, data cleaning, transformation and SQL-based business analysis on a Customer Shopping Behaviour dataset.

The objective is to prepare raw customer shopping data for analytical purposes and derive meaningful business insights into customer purchasing patterns, spending behaviour, product preferences, discounts, subscriptions and customer segmentation.

The project demonstrates practical data analytics capabilities using **Python, Pandas and PostgreSQL**, following a structured data preparation and analysis workflow.

## 🎯 Project Objectives

- Explore and profile customer shopping behaviour data.
- Identify missing values, data quality issues and inconsistencies.
- Clean and standardise dataset columns.
- Perform data transformations and feature engineering.
- Load the transformed dataset into PostgreSQL.
- Develop SQL queries to answer business questions.
- Apply advanced SQL concepts to derive customer and product insights.

## 🏗️ Project Workflow

The project follows these stages:

### 1. Data Extraction

- Import the customer shopping behaviour dataset from CSV.
- Load the dataset into a Pandas DataFrame.
- Inspect initial records and dataset structure.

### 2. Data Profiling and Quality Assessment

- Identify missing values using `isnull()`.
- Generate descriptive statistics using `describe()`.
- Examine column structures and data distributions.
- Identify missing customer review ratings.
- Check consistency between discount and promotional code indicators.

### 3. Data Cleaning and Transformation

The following transformations are implemented:

- Handle missing review ratings using category-level median values.
- Apply Pandas `groupby()` and `transform()` for group-level imputation.
- Standardise column names to lowercase.
- Replace spaces and special characters in column names.
- Create customer age groups using `pd.qcut()`.
- Convert purchase frequency categories into numerical day intervals.
- Validate discount and promotional code consistency.
- Remove redundant columns.

**Feature Engineering:**

| Feature | Description |
|---|---|
| `new_review_rating` | Missing review ratings imputed using category median |
| `age_group` | Customer segmentation into four age groups |
| `frequency_of_purchases_days` | Numerical representation of purchase frequency |

### 4. Database Loading

The transformed dataset is loaded into PostgreSQL using SQLAlchemy.

Key implementation details:

- PostgreSQL database: `customer_behaviour_db`
- Database table: `customer_behaviour`
- Python database connectivity using SQLAlchemy.
- DataFrame-to-database loading using `to_sql()`.

### 5. SQL Business Analysis

The SQL analysis addresses the following ten business questions:

| # | Business Question | SQL Concepts |
|---|---|---|
| 1 | What is the total revenue generated by male vs. female customers? | GROUP BY, SUM |
| 2 | Which customers used discounts but still spent more than the average purchase amount? | CTE, Window Functions |
| 3 | What are the top five products with the highest average review ratings? | AVG, ROW_NUMBER |
| 4 | How do average purchase amounts compare between Standard and Express shipping? | FILTER, CASE |
| 5 | Do subscribed customers spend more than non-subscribers? | GROUP BY, AVG, SUM |
| 6 | Which five products have the highest percentage of purchases with discounts applied? | CTE, Window Functions |
| 7 | How can customers be segmented into New, Returning and Loyal categories? | CASE, GROUP BY |
| 8 | What are the top three most purchased products within each category? | PARTITION BY, ROW_NUMBER |
| 9 | Are repeat buyers more likely to subscribe? | WHERE, GROUP BY |
| 10 | What is the revenue contribution of each age group? | Window Functions, Aggregations |

## ⚙️ Setup and Execution

### Prerequisites

- Python 3.x
- PostgreSQL
- Jupyter Notebook

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd customer-shopping-behaviour
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

Activate the environment:

Windows:

```bash
.venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install pandas numpy sqlalchemy psycopg2-binary jupyter
```

### 4. Configure PostgreSQL

Create the database:

```sql
CREATE DATABASE customer_behaviour_db;
```

Configure database connectivity using your local PostgreSQL credentials.
